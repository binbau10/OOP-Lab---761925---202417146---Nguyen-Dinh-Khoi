If you create a constructor method to build a DVD by title then create a constructor method to build
a DVD by category. Does JAVA allow you to do this?

No, because both constructors have the same signature. They have the same name and their parameter is String. The name of parameters (such as title or category) is not included in a signature

Try to add a method addDigitalVideoDisc which allows to pass an arbitrary number of arguments for dvd. Compared to an array parameter. What do you prefer in this case?

After the call of swap(jungleDVD, cinderellaDVD) why does the title of these two objects still remain?

Because the method only got the copied values (including references) of the objects. The copy also pointed to the same data region in the heap memory, and the method swapped their reference. The original objects still pointed to the original data region.

After the call of changeTitle(jungleDVD, cinderellaDVD.getTitle()) why is the title of the JungleDVD changed?

The method got a copy of JungleDVD which points to the region with title = "Jungle". It used the copied value (reference) to call setTitle which changed the refered object's title into "Cinderella". The later assignment only changed the reference, and the object was unchanged, keeping the title "Cinderella".
